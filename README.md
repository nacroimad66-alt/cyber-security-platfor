# منصة الأمن السيبراني

منصة عربية RTL مبنية باستخدام Node.js وExpress وSQLite.

## التشغيل محلياً
1. ثبّت Node.js إصدار 20 أو أحدث.
2. انسخ `.env.example` إلى `.env` وعدّل `SESSION_SECRET` وكلمة مرور المدير.
3. نفّذ `npm install` ثم `npm start`.
4. افتح `http://localhost:3000`.

## النشر
يمكن النشر على Render عبر ربط مستودع GitHub، واختيار Web Service، وأمر البناء `npm install` وأمر التشغيل `npm start`. أضف متغيرات البيئة `SESSION_SECRET` و`ADMIN_USERNAME` و`ADMIN_PASSWORD`، واستخدم قرصاً دائماً لمسار قاعدة البيانات `DB_PATH` حتى لا تضيع البيانات عند إعادة النشر.

## تنبيه
الأدوات المضمنة تعليمية ومحدودة. لا تفحص أنظمة أو شبكات دون إذن صريح. قبل الاستخدام الفعلي، راجع إعدادات الجلسات وCSRF ونسخ قاعدة البيانات، واختبر التطبيق أمنياً.
